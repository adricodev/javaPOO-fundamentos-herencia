# ejercicio-poo-personas
#Java POO - Fundamentos herencia
Primer ejercicio práctico de programación orientada a objetos en Java.

#Descripción
Este ejercicio contiene las siguientes clases "Persona", "Cliente", "Empleado" y "Gerente".

#Objerivo
Practicar conceptos básicos de Java y POO:
- Clases y objetos.
- Atributos.
- Herencia.
- Sobreescritura de métodos.
- Uso de super
