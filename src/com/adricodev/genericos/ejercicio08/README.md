# Ejercicio 08 — Intercambio de Posiciones (swap genérico)

## Enunciado

Crear una clase `ArrayTransformUtils` con un método estático genérico `intercambiarPosiciones(T[] array, int pos1, int pos2)` que intercambie los elementos de dos posiciones del array.

En el main, crear un array de `Integer`, intercambiar dos posiciones e imprimir el resultado con `Arrays.toString()`.

## Clases

- `ArrayTransformUtils` — clase utilitaria con el método genérico de intercambio
- `Main` — prueba con un array de Integer

## Conceptos practicados

- Variable temporal para intercambiar valores (algoritmo swap)
- Mutación de arrays genéricos por índice
- Impresión legible de arrays con `Arrays.toString()`
