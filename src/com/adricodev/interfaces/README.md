# Módulo: Interfaces

Ejercicios centrados en el uso de **interfaces** en Java: contratos entre clases, implementación múltiple, polimorfismo con interfaces y separación de comportamiento. Los ejercicios progresan desde una clase abstracta (antesala) hasta interfaces combinadas con herencia.

## Ejercicios

| # | Ejercicio | Qué aprenderás |
|---|-----------|----------------|
| 01 | [Figuras Geométricas](./ejercicio01/) | Clase abstracta como antesala directa a las interfaces |
| 02 | [Voladores](./ejercicio02/) | Primera interfaz, métodos `default` y `static` |
| 03 | [Medios de Pago](./ejercicio03/) | Combinar `extends` e `implements` |
| 04 | [Procesador de Pagos](./ejercicio04/) | La interfaz como tipo de parámetro + casting |
| 05 | [Dispositivos](./ejercicio05/) | Implementación múltiple y `instanceof` entre interfaces |
| 06 | [Canales de Notificación](./ejercicio06/) | Un contrato, distintas implementaciones |

## Conceptos que se practican

- Declaración de interfaces
- Implementación de interfaces (`implements`)
- Polimorfismo con tipos de interfaz
- Métodos por defecto (`default`) y estáticos (`static`)
- Diferencias entre interfaz y clase abstracta
