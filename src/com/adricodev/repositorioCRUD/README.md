# Módulo: Repositorio CRUD

Ejercicios centrados en el patrón **repositorio** y operaciones **CRUD** (Create, Read, Update, Delete) en Java: abstracción del acceso a datos, colecciones y separación de capas. La dificultad crece desde un repositorio simple hasta consultas personalizadas con estructura por paquetes.

## Ejercicios

| # | Ejercicio | Qué aprenderás |
|---|-----------|----------------|
| 01 | [Repositorio de Facturas](./ejercicio01/) | Primer repositorio: interfaz + implementación sobre ArrayList |
| 02 | [Repositorio de Clientes](./ejercicio02/) | Repetir el patrón con otro modelo de datos |
| 03 | [Repositorio de Productos](./ejercicio03/) | CRUD completo añadiendo la actualización |
| 04 | [Libros por capas](./ejercicio04/) | Organización en subpaquetes modelo / interfaces / implementacion |
| 05 | [Empleados por capas](./ejercicio05/) | Consolidar la estructura por capas |
| 06 | [Libros con Búsquedas](./ejercicio06/) | Consultas filtradas: porAutor() y conPrecioMayor() |

## Conceptos que se practican

- Patrón repositorio con interfaces
- Operaciones CRUD sobre colecciones
- Búsquedas y filtrados de datos
- Separación de responsabilidades (capa de datos vs. lógica)
- Organización del código en subpaquetes
